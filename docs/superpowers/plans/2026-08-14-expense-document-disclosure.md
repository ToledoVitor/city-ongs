# Expense Document Disclosure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let users expand expenses, fetch attached documents on demand, explicitly assign selected documents, and unlink mistaken documents in place.

**Architecture:** Add one read-only, accountability-scoped JSON endpoint for paginated expense documents. Keep existing assignment endpoint as single write seam for assignment and unlinking. Rebuild expense card as article containing disclosure button, explicit assignment button, drop target, and lazy cached document list.

**Tech Stack:** Python 3.12, Django, Django TestCase, Django templates, vanilla JavaScript, existing SITTS UI tokens.

## Global Constraints

- Preserve existing accountability permissions, execution-state checks, upload validation, and `assign_expense_documents_view` write contract.
- Endpoint pagination defaults to 20 items and caps `page_size` at 50.
- Expense summary click only expands or collapses; it never assigns.
- `Vincular N` is explicit assignment action; drag-and-drop remains supported.
- Eye actions open new tab with `noopener`; unlink actions never delete files.
- Only one expense disclosure stays open; successful fetched pages stay cached until assignment or unlink invalidates them.
- Desktop fits 1366×768 without body scroll; mobile avoids horizontal scroll and keeps 44 px touch actions.
- Do not add dependencies or migrations.
- Do not stage `AGENTS.md`, `docs/agents/`, temporary files, or unrelated user changes.

```python
@require_GET
@login_required
def expense_document_expense_documents_view(request, pk, expense_pk):
    accountability = get_object_or_404(Accountability, id=pk)
    if not request.user.can_update_accountability or not accountability.is_on_execution:
        return JsonResponse({"error": "Consulta não permitida."}, status=403)
    expense = get_object_or_404(
        Expense,
        id=expense_pk,
        accountability=accountability,
        deleted_at__isnull=True,
    )
    documents = ExpenseFile.objects.filter(
        accountability=accountability,
        expense=expense,
        deleted_at__isnull=True,
    ).order_by("-created_at", "pk")
    total = documents.count()
    rows, has_more, page = _workspace_page(request, documents)
    return JsonResponse(
        {
            "results": [_serialize_expense_document(document) for document in rows],
            "page": page,
            "has_more": has_more,
            "total": total,
        }
    )
```

Extract `_serialize_expense_document(document)` so document feed and disclosure endpoint share `id`, `name`, `url`, and `is_image`. Add `documents_url` to expense serializer with named route.

- [ ] **Step 4: Implement per-document unlink refresh**

On failure, re-enable action, preserve row, and show error alert.
